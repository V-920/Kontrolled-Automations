LOCAL DEPLOYMENT GUIDE

Your n8n.
On your computer.

This development setup runs n8n in Docker and uses the Kontrolled Companion to install workflows through the n8n API.

Before you start

  • Windows, macOS or Linux with Docker Desktop / Docker Engine installed.
  • Node.js 20.11 or later.
  • The Kontrolled project folder.
  • Keep your computer awake while scheduled automations need to run.

1. Start n8n

From the project directory, run: 

docker compose up -d

Open http://127.0.0.1:5678 and complete n8n's owner-account setup.

2. Create an n8n API key

In n8n, open your personal settings and create an API key. Treat it like a password. Do not share it or commit it to source control.

3. Configure Kontrolled

The project includes a configured .env file. Its generator webhook is set to http://localhost:5678/webhook/automation-factory . Copy the value of KONTROLLED_ACCESS_TOKEN from that file into the Automation Builder's Developer access settings. Paste the n8n API key into LOCAL_N8N_API_KEY .

4. Start Kontrolled 

npm start

In another terminal, start the companion: 

npm run companion

Open http://127.0.0.1:3000 , go to Automation, enter your backend access token in Developer access settings, then connect the local companion using the companion token from .env .

5. Deploy and review

Generate or import a workflow, validate it, then deploy locally. Kontrolled creates it inactive. Open n8n, connect any required credentials, inspect every node, test the workflow and activate it yourself when satisfied.

Limitations: Local workflows run only while your computer and Docker service are running. Webhook triggers that must receive requests from the public internet need a secure, reachable webhook URL or tunnel. Do not expose the n8n editor or Docker socket directly to the internet. This local setup is a developer MVP, not a one-click installer.
